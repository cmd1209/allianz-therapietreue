# Dm Sans

Locally hosted normal static TrueType faces: 400/500/600/700. Google Fonts builds downloaded 23 October 2026; each OS/2 weight was verified before registration. DM Sans uses optical size14 to match Figma. Alan500 is retained for compatibility with saved font choices. No runtime Google Fonts request.
